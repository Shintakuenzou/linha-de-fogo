# Linha de Fogo

Tiro tático 5 contra 5 em primeira pessoa no navegador. Atacantes plantam a bomba no ponto A ou B; defensores desarmam. Crie uma sala, mande o link e complete os times com bots.

Jogue em: https://shintakuenzou.github.io/linha-de-fogo/

Feito com three.js. Salas online passam por servidores MQTT públicos (EMQX, HiveMQ, Mosquitto).
