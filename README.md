# Linha de Fogo

Tiro tático 5 contra 5 em primeira pessoa no navegador, numa vila no deserto. Terroristas plantam a bomba no ponto A ou B; forças especiais desarmam. Economia por rodada com menu de compra, 8 classes com funções próprias e recuo diferente em cada arma. Os modelos são originais, feitos em código a partir das formas das armas reais.

Jogue em: https://shintakuenzou.github.io/linha-de-fogo/

Feito com three.js. Salas online passam por servidores MQTT públicos (EMQX, HiveMQ, Mosquitto).
